# 位姿融合和TF管理系统集成指南

## 概述

本文档介绍了新设计的位姿融合节点和TF树维护节点的功能、架构和使用方法。

## 系统架构

### 1. 位姿融合节点 (pose_fusion)

#### 功能
- 接收来自SLAM、AMCL和IMU的姿态估计
- 使用扩展卡尔曼滤波器进行数据融合
- 提供置信度评估
- 输出高精度的机器人位姿估计

#### 输入
- `slam_pose`: SLAM提供的位姿估计
- `amcl_pose`: AMCL粒子滤波器位姿估计
- `imu_data`: IMU传感器数据（角速度等）
- `timer`: 定时更新触发器

#### 输出
- `fused_pose`: 融合后的高精度位姿估计
- `confidence`: 位姿估计的置信度

### 2. TF树维护节点 (tf_manager)

#### 功能
- 维护机器人各传感器的坐标系关系
- 管理静态和动态坐标变换
- 提供统一的坐标变换服务
- 支持闭环修正

#### 坐标系定义
```
map (全局地图坐标系)
  ↕ 
odom (里程计坐标系)
  ↕ 
base_link (机器人本体坐标系)
  ↕ 
laser (激光雷达坐标系)
```

#### 输入
- `fused_pose`: 融合后的位姿估计
- `slam_correction`: SLAM闭环修正信息
- `timer`: 定时发布TF变换

#### 输出
- `tf_transforms`: TF坐标变换数据

## 构建方法

### 1. 自动构建
```bash
./build_new_nodes.sh
```

### 2. 手动构建

#### 构建位姿融合节点
```bash
cd build/pose_fusion
mkdir -p build
cd build
cmake ..
make -j$(nproc)
```

#### 构造TF管理节点
```bash
cd build/tf_manager
mkdir -p build
cd build
cmake ..
make -j$(nproc)
```

## 坐标系统一方案

### 问题解决
1. **度量单位统一**: 全部转换为米(m)和弧度(rad)
2. **原点统一**: 建立标准的坐标系原点定义
3. **变换链**: 通过TF树管理各坐标系间的关系
4. **数据融合**: 多传感器数据融合提高精度

### 变换精度改进
- SLAM提供高精度的地图级定位
- AMCL提供鲁棒的自定位
- IMU提供高频的姿态更新
- TF树确保变换的一致性

## 配置参数

### 位姿融合参数
- **卡尔曼滤波噪声**: 根据传感器精度调整
- **置信度阈值**: 用于判断数据质量
- **更新频率**: 建议50-100Hz

### TF管理参数
- **静态变换**: 传感器安装位置参数
- **动态变换频率**: 建议10-50Hz
- **时间同步**: 确保变换的时间一致性

## 故障排除

### 常见问题
1. **编译错误**: 检查依赖库是否正确安装
2. **运行时崩溃**: 检查输入数据格式
3. **精度问题**: 调整卡尔曼滤波参数

### 调试建议
1. 开启详细日志输出
2. 监控各节点的数据流
3. 检查TF变换的连续性
